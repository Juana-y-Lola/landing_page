## The project

Pixban is an image editor that lets you pixelate specific areas using rectangles or a brush. You can select a rectangular area or apply pixelation freehand to the parts of an image you want to edit.

Its main use case is sharing an image quickly while hiding the sensitive information it contains before sending it.

You can import images from files, paste them from the clipboard, or drag and drop them into the editor. Once you have edited an image, you can copy the result to the clipboard or save it to a file to share it.

It is a 100% free, secure, and freely available tool, with its repository available on GitHub.

## Built with

The application is built with React and Codex, and deployed on ChatGPT Sites.
