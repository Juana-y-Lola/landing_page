## The idea

EasyParse CV explores a straightforward way to turn a PDF résumé into structured information. It extracts personal details, experience, education, certifications, and skills through text parsing and data extraction, without relying on external services.

## How it works

Drop or select a PDF of up to 4 MB, then start the analysis. The demo says it processes the file in memory for that request and does not store, log, or share it with third parties.

This is a concept project built for experimentation and learning, not a production tool.
